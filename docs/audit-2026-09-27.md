# peco UI 現状監査（2026-09-27）

デザイントークン拡張と Button / Badge 抽出の設計根拠。対象は peco `src/**/*.tsx` 318 ファイル
（テスト除外）、dev HEAD。トークンの「事実上のスケール」は理想論でなく**この実測**から採る
（要件定義 `docs/v2/requirements/25_design-system.md` §2-2）。

## 1. ボタン様要素: 630 件・ユニークな色シグネチャ 93 種

`<button>` 499 + ボタン風 `<Link>` 89 + `<a>` 42。**汎用 Button コンポーネントは存在しない**。
ただし `DangerZone.tsx` に危険系の共有クラス定数が 4 つあり計 106 箇所から参照されている
（同ファイルの設計方針は「寸法は呼び出し側・色/枠/太さだけ共有」）。

### 事実上の variant 分類（実測 n）

| variant | n | 代表構成 |
|---|---:|---|
| primary | 151 | `bg-accent text-white font-semibold rounded-xl` |
| ghost / bare | 127 | 色・rounded なし（アイコンボタン等） |
| secondary | 119 | `bg-card border border-border font-semibold rounded-xl` |
| soft（accent-tint） | 85 | `bg-accent-bg` / `bg-accent/10` + `text-accent` |
| danger | 72 | 定数 `DANGER_*_CLASS` 54 + インライン 18。red-600 基調 |
| outline | 46 | `border border-border`（bg なし）`font-semibold`（41/46 でほぼ統一） |
| success（LINE 緑） | 21 | `bg-success text-white`。**`bg-[#06C755]` 直書きが 4 件混入** |
| warning | 10 | amber 系 |
| inverse | 8 | `bg-foreground text-white` |
| 外れ値 | 33 | gray-100 擬似 disabled 10 / カレンダーブロック 3 / blue 系 3 / その他 |

### ばらつき（正規化の対象）

- **padding**: primary だけで 10 パターン以上（`py-3.5` 31 / `py-3` 29 / `px-4 py-2.5` 11 …）
- **タップ領域の担保が 4 流派**: `min-h-[2.75rem]` 17 / `min-h-[3rem]` 7 / `min-h-[44px]` 1 / `h-10/11/12` 計 11
- **rounded**: `rounded-xl` が最頻（primary 116/151）。`-lg` / `-full` / `-2xl` が併存
- **disabled**: 630 件中 disabled 指定は約 130 件のみ。**opacity が 7 段階**（20/30/35/40/50/60/80）
- **active**: `scale-[0.98]` / `scale-[0.99]` / `scale-95` の 3 値 + opacity 系 4 値。
  globals.css のタッチフィードバック用 transition は `[0.98]` / `[0.99]` しかカバーしない
  （**`active:scale-95` はトランジション無しで動く**）
- **hover**: primary 151 件中 21 件のみ。`bg-accent/90` / `bg-accent-dark` / `opacity-90` の 3 通り
  （`--accent-dark` トークンがあるのに `accent/90` が多数派）
- **transition**: `transition-colors` 95 / `transition` 71 / `transition-all` 62 / 他

## 2. バッジ: コンポーネント 3 個 vs インライン 191 件

`ExpiredBadge` / `ResourceBadge` / `InvoiceStatusBadge` は rounded・text size・font・padding が
**全部異なる**（rounded-md/rounded/rounded-full、10px/9.5px/12px、semibold/bold）。
インライン実装 191 件（span 136 / p 34 / div 21）の最頻構成:

- rounded: `rounded-full` 99（過半） / text: `text-[10px]` 76・`text-xs` 52・`text-[11px]` 31（**11 段階に分裂**）
- padding: `px-2 py-0.5` 53 / `px-1.5 py-0.5` 33 / `px-2.5 py-1` 14 …
- 枠: `ring-1` 44 / tone: accent-bg 22・amber 系 34・red 系 24・green+emerald 系 22・gray 系 12
- **green と emerald が同義で二重化**（計 214 回・トークンで green に統一する）

## 3. スタイル頻度（トークン設計の根拠）

- **rounded**(1541): `xl` 587 / `full` 332 / `2xl` 304 / `lg` 217 / `md` 53 → 役割トークンは
  `radius/control = 0.75rem(xl)`・`radius/surface = 1rem(2xl)` の 2 つで大勢をカバー
- **shadow**(377): `shadow-sm` 167 が支配的。色付き `shadow-accent-*` 64。
  任意値 shadow 4 種は accent/foreground の RGB を数値写経（トークン化漏れ）
- **text size**(2816): `sm` 888 / `xs` 854 / **`[11px]` 256 / `[10px]` 166** — xs より下の段への
  強い需要 → `text/2xs = 11px`・`text/3xs = 10px` を新設。任意値は 32 種・全体の約 24%
- **font-weight**(1697): `semibold` 844 / `bold` 457 / `medium` 312。実質 3 段
- **spacing**: Tailwind 標準スケールで運用されておりカスタム値はごく僅か → **spacing トークンは新設しない**
- **枠**: 1px 枠が `border`(1736) と `ring-1`(492) に二重化。カードは ring・フォームは border の
  暗黙の慣習あり（未文書）

## 4. トークン外の色（計 1598 回）と対応

| 欠落 | 実測 | 対応（v0.2 で追加） |
|---|---|---|
| danger 系 | red 333 回 | `danger`={red.600} / `danger-bg`={red.50} |
| warning 系 | amber 268 + orange 42 | `warning`={amber.700} / `warning-bg`={amber.50} |
| 成功（UI 一般） | green 115 + emerald 99 | `positive`={green.600} / `positive-bg`={green.50}（LINE 緑の `success` とは別トークン） |
| info 系 | blue 68 + sky/indigo 25 | `info`={blue.700} / `info-bg`={blue.50} |
| 濃色塗り上の文字 | text-white 254 | `on-accent`={white} |
| 無彩色 gray | 137 回 | プリミティブのみ収載。新規コードは warm neutral を優先 |
| ロゴのモーヴ | hex 直書き 10 回 | プリミティブ `mauve.500` に収載済み |
| hex 直書き | 47 回 | 対応するトークンへの置換対象リストとして本監査を参照 |

ステータス系プリミティブの値は **Tailwind v4 パレットの oklch をそのまま**収載
（hex 化すると v4 の描画と微差が出るため）。

## 5. Button / Badge の設計インプット（→ 実装 Issue へ）

- **Button**: variant 9 種で全域の 95% をカバー。size は `sm / md / lg` の 3 段に正規化
  （最頻 padding から `sm=px-3 py-1.5 text-xs` / `md=px-4 py-2.5 text-sm` / `lg=px-4 py-3.5 text-sm` 起点）。
  rounded は `radius/control` 既定。disabled は `opacity-50 + cursor-not-allowed` に一本化、
  active は `scale-[0.98]` に一本化
- **Badge**: `tone`(neutral/accent/danger/warning/positive/info) × `variant`(solid/soft/outline) ×
  `size`(sm=`px-2 py-0.5 text-3xs font-bold` / md=`px-2.5 py-1 text-xs font-semibold`)、`rounded-full` 既定
- **対象外**: スケジュールのカレンダーブロック（絶対配置・可変高の別物）、gray-100 擬似 disabled
  （disabled 属性への是正対象）

## 6. コア部品の昇格依存（実測）

- 依存ゼロで即昇格可: Spinner(43 呼出) / Alert(48) / PageContainer(26) / FormField(26+21+11) /
  StepProgress / Pagination / SheetActions / Toggle
- 1 段依存: NumberField→FormField / TabFilter→Tabs / FullScreenLoading→Spinner+PecoLogo
- 引き剥がしが必要: Modal(→dialog-behavior。一緒に移す) / SelectDropdown(→use-is-desktop) /
  **Tabs(→navigation/history-depth + next/link。履歴管理に密結合 — コールバック注入に変える必要**)
- アイコン 24 個（icons.tsx 23 + PecoLogo）。`SVGProps` を受けるのは PecoLogo だけで API 不統一。
  ChevronDown/Up・Warning・Info 等は未定義でインライン svg が散在
